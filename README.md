# ♠ ポーカーディーラー

テーブルの真ん中に置いた携帯 1 台をディーラー代わりにするための Web アプリ（PWA）です。
テキサスホールデム（ノーリミット）のチップ計算・ポット表示・手番管理を担当します。
カードは実物のトランプで配っても、アプリに配らせても（トランプが無い時）どちらでも使えます。

## できること

- **人数 2〜10 人**、名前・初期スタック・SB/BB を設定して開始
- **カード**: 「トランプを使う」（勝者はタップで選ぶ）／「アプリが配る」（仮想デッキで配り、役判定と配分まで自動。自分の手札は手番のときに「手札を見る」を長押しして確認、ボードは中央に表示）
- **別の携帯に引き継ぐ**: メニューから引き継ぎリンクを作って LINE などで送ると、開いた携帯で進行中のハンドの手札ごと続きから再開できる（充電切れ対策）
- **アンテ方式**: BB アンテ（デフォルト）／全員アンテ／なし
- **キャッシュゲーム**（ブラインド固定、リバイ・途中参加・退席あり）と **トーナメント**（タイマー付きブラインドアップ、敗退管理）
- ディーラーボタンの自動移動、ブラインド・アンテの自動徴収
- 今誰の番か、コール額、最低レイズ額を表示。操作は「フォールド／チェック・コール／レイズ／オールイン」をタップするだけ
- レイズ額はスライダー、1/2 Pot・Pot などのクイックボタン、±BB で調整
- **オールイン時のサイドポット自動計算**。ショーダウンでは勝った人をタップするだけで配分（引き分けは複数選択）
- **「戻す」で直前の操作を取り消し**（誤タップ対策）
- 途中でブラインド／アンテ変更、プレイヤー追加、名前変更、離席、ミスディール（ハンド中止）
- 終了時に **収支サマリー**（持込・最終・収支）
- **言語切替**: 日本語／中文（簡体字）。中文モードでは各文言の下に小さく日本語を併記
- 状態は操作のたびに端末へ自動保存（localStorage と IndexedDB の二重保存）。ブラウザを閉じても続きから再開。保存に失敗すると画面下に赤い警告
- **ハンド履歴・復元**: 各ハンド終了時のスタックを記録し、任意のハンド終了時点に戻せる（メニュー）
- **前回のゲームの保管**: 「新しいゲーム」を始めても前のゲームは次のゲームが終わるまで残り、設定画面から結果表示・復元ができる
- **バックアップ**: メニューから状態を文字列としてコピーし、設定画面で貼り付けて復元できる（機種変更・別端末への引き継ぎにも）
- オフラインでも動作（Service Worker）。画面スリープ防止（対応端末）

## 使い方（ホーム画面に追加）

1. 上の URL を携帯のブラウザで開く
2. iPhone: Safari の共有ボタン →「ホーム画面に追加」／ Android: Chrome のメニュー →「ホーム画面に追加」または「アプリをインストール」
3. ホーム画面のアイコンから起動するとフルスクリーンで使えます

## ローカルで動かす

静的ファイルだけなので、任意の HTTP サーバーで配信できます。

```
python -m http.server 8000
# → http://localhost:8000/
```

```
npm test
```

## 構成

| ファイル | 役割 |
| --- | --- |
| `engine.js` | ルールエンジン（手番、ブラインド、アンテ、最低レイズ、サイドポット、タイマー、仮想カード配布と自動ショーダウン）。UI 非依存 |
| `cards.js` | デッキ・シャッフル（CSPRNG）・7 枚から最良 5 枚の役判定 |
| `app.js` | 画面描画・操作・保存 |
| `i18n.js` | 日本語→中国語の翻訳辞書（キーは日本語の文言そのもの） |
| `index.html` / `style.css` | 画面 |
| `manifest.webmanifest` / `sw.js` / `icons/` | PWA（ホーム画面追加・オフライン） |
| `tests/*.test.js` | エンジンと役判定のテスト |

## 採用しているルール

- ヘッズアップ時はディーラーが SB。プリフロップはディーラーから、フロップ以降は BB からアクション
- BB アンテは BB がブラインドを先に払い、残りでアンテを払う
- 最低レイズは直前のレイズ幅以上。それに満たないオールインは、既にアクション済みのプレイヤーのレイズ権を復活させない
- 端数チップはディーラーの左隣から順に配る
- ディーラーボタンは次の参加プレイヤーへ単純移動（デッドボタンなし）
