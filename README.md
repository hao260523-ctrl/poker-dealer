# ♠ ポーカーディーラー

トランプしかない時に、テーブルの真ん中に置いた携帯 1 台をディーラー代わりにするための Web アプリ（PWA）です。
テキサスホールデム（ノーリミット）のチップ計算・ポット表示・手番管理を担当します。カードは物理のトランプで配ってください。

## できること

- **人数 2〜10 人**、名前・初期スタック・SB/BB を設定して開始
- **アンテ方式**: BB アンテ（デフォルト）／全員アンテ／なし
- **キャッシュゲーム**（ブラインド固定、リバイ・途中参加・退席あり）と **トーナメント**（タイマー付きブラインドアップ、敗退管理）
- ディーラーボタンの自動移動、ブラインド・アンテの自動徴収
- 今誰の番か、コール額、最低レイズ額を表示。操作は「フォールド／チェック・コール／レイズ／オールイン」をタップするだけ
- レイズ額はスライダー、1/2 Pot・Pot などのクイックボタン、±BB で調整
- **オールイン時のサイドポット自動計算**。ショーダウンでは勝った人をタップするだけで配分（引き分けは複数選択）
- **「戻す」で直前の操作を取り消し**（誤タップ対策）
- 途中でブラインド／アンテ変更、プレイヤー追加、名前変更、離席、ミスディール（ハンド中止）
- 終了時に **収支サマリー**（持込・最終・収支）
- 状態は端末に自動保存。ブラウザを閉じても続きから再開。オフラインでも動作（Service Worker）。画面スリープ防止（対応端末）

## 使い方（ホーム画面に追加）

1. 上の URL を携帯のブラウザで開く
2. iPhone: Safari の共有ボタン →「ホーム画面に追加」／ Android: Chrome のメニュー →「ホーム画面に追加」または「アプリをインストール」
3. ホーム画面のアイコンから起動するとフルスクリーンで使えます

## ローカルで動かす

静的ファイルだけなので、任意の HTTP サーバーで配信できます。

```
python -m http.server 8000
# → http://localhost:8000/
```

## 公開（GitHub Pages）

リポジトリ: https://github.com/hao260523-ctrl/poker-dealer （`main` ブランチのルートから配信）

## テスト

ルール処理（`engine.js`）は Node の標準テストランナーで検証しています。

```
npm test
```

## 構成

| ファイル | 役割 |
| --- | --- |
| `engine.js` | ルールエンジン（手番、ブラインド、アンテ、最低レイズ、サイドポット、タイマー）。UI 非依存 |
| `app.js` | 画面描画・操作・保存 |
| `index.html` / `style.css` | 画面 |
| `manifest.webmanifest` / `sw.js` / `icons/` | PWA（ホーム画面追加・オフライン） |
| `tests/engine.test.js` | エンジンのテスト |

## 採用しているルール

- ヘッズアップ時はディーラーが SB。プリフロップはディーラーから、フロップ以降は BB からアクション
- BB アンテは BB がブラインドを先に払い、残りでアンテを払う
- 最低レイズは直前のレイズ幅以上。それに満たないオールインは、既にアクション済みのプレイヤーのレイズ権を復活させない
- 端数チップはディーラーの左隣から順に配る
- ディーラーボタンは次の参加プレイヤーへ単純移動（デッドボタンなし）
